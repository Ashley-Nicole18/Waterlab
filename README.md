# WaterLab Digital Management System

A LAN-based digital management system designed to support
WaterLab's internal laboratory operations.

## Project Structure

- `apps/web` - Frontend application
- `apps/api` - Backend application
- `database/migrations` - Database schema migrations
- `database/seeds` - Initial and sample database records
- `docs/architecture` - Architecture documentation
- `docs/requirements` - System requirements documentation

## Architecture

The project is planned as a client-server application
following a modular monolith architecture.
